## Uso como Skill

Instalar directamente como skill para Qwen Code / Claude Code:

```bash
# Clone este repo o copie SKILL.md a tu directorio de skills
cp SKILL.md ~/.qwen/skills/premium-effects-registry/SKILL.md
```

La skill se dispara automáticamente al mencionar: `efectos premium`, `liquid logo`, `3d webgl`, `shader glsl`, `particle effect`, `gsap animation`, `cyberpunk ui`, `creative coding`, etc.
