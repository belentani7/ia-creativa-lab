Architecture

AI Providers
Every provider is a plugin. The built-in engine always works — cloud providers activate only when you add a key to .env.local on the server. When one fails, FireLab falls back down this order automatically.

Refresh
Secrets never touch the browser. Keys are read server-side from environment variables only — never in the repo, never in client code, never in logs. The demo engine is a labeled last-resort fallback, not fake AI.
