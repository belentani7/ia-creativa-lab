# Backlog Priorizado de Excelencia - Firefly Studio

## 1. Mejoras de Calidad y Experiencia de Usuario (UX)
- **Historial de Variaciones:** Permitir ver múltiples variaciones generadas en una sesión para el mismo prompt.
- **Indicador de Calidad en Tiempo Real:** Mostrar el desglose de la puntuación de calidad del prompt optimizado en la interfaz.

## 2. Endurecimiento de Seguridad y Backend
- **Límites de Petición por Usuario:** Reforzar la validación de tamaño y tipo MIME en todas las cargas base64.
- **Validación Estricta de Máscaras:** Asegurar que las imágenes de máscara en Generative Fill cumplan con dimensiones compatibles con el modelo base.

## 3. Rendimiento y Accesibilidad (A11y)
- **Foco Visible y ARIA:** Mejorar los atributos de accesibilidad en modales, botones de control y selectores de ratio.
- **Optimización de Carga:** Comprobar que los assets estáticos externos sigan políticas de caché eficientes.
