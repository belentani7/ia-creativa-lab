# lumen-local-studio

Lumen Local Studio - estudio visual local (cliente + servidor).

## Requisitos
- Node.js 20+

## Instalacion
```bash
git clone https://github.com/belentani7/lumen-local-studio.git
cd lumen-local-studio
pnpm install
```

## Uso
```bash
npm run dev
```
